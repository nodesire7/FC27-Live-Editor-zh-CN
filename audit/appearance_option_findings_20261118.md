## 证据

- 袜长：EXE `0x7b96a1a..0x7b96a60` 青训外观生成器将 Average / Short / High 与显式 ID 0 / 1 / 2 组成配置权重记录。
- 袜长 UI：`0x7155521..0x715559e` 构造 Average / Short / High / Ultra Low 的连续标签；`0x7155695..0x71556b1` 构造明确的 0 / 1 / 2 / 3 选项 ID。当前值也直接用于同标签向量索引。
- 打底裤：`0x7b96512` 将 esi 清零；`0x7b96546` 设置 r14d=1；`0x7b96761..0x7b96789` 分别将 Undershorts / Leggings 与这两个 ID 成对保存。
