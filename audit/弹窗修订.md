# 27.2.0 署名弹窗修订

旧版在 Present 的 ImGui::Render 前绘制，这时 LE 本帧已经恢复默认字体。新版本使用 LE 自身对话框调用点 0x46C478，保留原函数参数和调用顺序。该位置在字体压栈 0x46C226 之后，并受 LE 可见和交互分支控制。继续使用原初始化完成标志。关闭按钮或前台 Esc 调用 EndPopup 前先执行 CloseCurrentPopup，并锁定本次启动的关闭状态。

历史渲染审计对应 v2026.11.18.1。新版以 CODE/src/StartupNotice.h 与 CODE/tests/check_patch.cpp 为准。
